# 自定义策略模拟

页面入口为“策略模拟”（`/?page=sim`）。新建与另存会生成一套暂停的策略；启动后由服务后台检查，关闭浏览器仍继续。暂停会取消未成交委托并停止该策略的退出检查。

每套初始10万元，默认北京时间14:30买入、最多5只、总仓位70%、单只10%，止盈观察线+10%、基础止损−5%；页面可修改。最多同时运行3套。买入检查窗口2分钟，行情不全会等待，错过不补单。委托只在后续有效新分钟模拟成交，包含T+1、费用、最小交易单位和流动性约束。

## 公式与股票池

中文方法说明用于记录；执行的是通过验证的公式，不直接执行自然语言或任意程序。例如：

```
M5:=MA(C,5);
M20:=MA(C,20);
选股:C>M5 AND M5>M20 AND V>MA(V,5);
```

支持日线OHLCV、实际可用的AMOUNT，以及MA、EMA、SMA、REF、HHV、LLV、SUM、COUNT、EVERY、EXIST、CROSS、ABS、MAX、MIN、IF、BARSLAST、BARSCOUNT、CODELIKE、NAMELIKE、ZTPRICE。所需历史不足或字段缺失会报数据不足。排序可选综合评分或自定义公式。新策略默认综合评分，历史策略保留已保存的排序方式。默认选股范围为沪深主板、创业板、科创板，可分别勾选；排除北交所、B股、基金、债券。选择“已选市场全部股票”时，从沪深交易所完整名录逐只检查日线公式，不受50只限制。页面展示扫描总数、完成数、数据失败和全部入选股票，并保留来源及获取时间。扫描耗时取决于行情可用性，完成前或有数据失败时不按残缺排名买入。全部入选保留展示，排序前50名再获取实时分钟并重新核验公式，受持仓和仓位约束后下单。各股日线获取时刻不同，不是同一秒快照。

自定义策略的公式选股、综合分与成交前公式复核统一使用**前复权日K，最多最近500根**，以每次获取时点的复权结果为准，历史不足不补造。东方财富前复权接口失败时切换腾讯明确返回的前复权日线；当前普通通达信节点与Tushare适配仅提供不复权数据，不作为前复权备用。两个前复权源都失败时记为数据失败，不退回不复权计算。来源、复权口径与实际日线根数随检查结果记录。以前保存的检查记录保留原来源，更新代码不追溯改写历史结果；需重新检查才能获得前复权结果。不同数据源的复权因子、精度及盘中快照仍可能不同，需与通达信实际选股逐项对照，不能因此宣称全市场一致。

模拟成交、估值、分时退出、成本与已有涨停保护仍使用实际价格及不复权历史；公式专用前复权序列独立传递，不能把复权历史价作为成交价或既有持仓的止损价。前复权源失败只阻止新买入的公式核验，已有持仓仍按可用的实际行情监控。

自定义股票池仍最多50只，也可选择当前已完成的主线或三维候选池；这些较小的池也按所选市场过滤。默认公式只是示例。

完整市场扫描在服务后台进行，一次只运行一套以控制数据请求；启用的策略在交易时段提前扫描，完成结果短时复用。扫描失败等待重试，不保证免费行情在买入窗口前完成。已有持仓的分钟退出检查独立运行。服务重启后重新扫描，已有策略账本保留。

每套全市场扫描使用4个工作线程并发获取和计算个股，三套全市场扫描依次排队；策略引擎最多3线程检查三套策略，每套的持仓/候选实时行情最多4线程读取。并发主要用于等待网络，不等于数据源支持无限并发；接口内部限流或市场名录请求仍会影响速度。

## 退出与浮盈保护

- 涨速口径为相邻且连续的最近1分钟收盘涨跌幅，不跨午休计算。
- 观察到买入后的涨停时暂不止盈，产生消息，将止损保护线至少抬至涨停价，止盈线至少抬至涨停价乘以原止盈比例；保护线只升不降。此前交易日已确认的收盘涨停也用于次日保护。观察到炸板则触发退出。
- 达到止盈观察线后，若1分钟涨速为负，或者跌破分时均价线，触发退出。量增价升且涨速大于1%时继续观察；其余情况等待退出条件。
- 以下浮盈保护条件独立检查，**不要求先到固定止盈线**，但当前价格须高于含买入费用的持仓成本。默认启用下穿均价线，其余可选。

| 条件 | 当前量化口径 |
| --- | --- |
| 下穿分时均价线 | 前一分钟收盘在均价线上或相等，当前收盘低于均价线 |
| 反弹受阻 | 前5分钟至少3根低于均价线；上一根距离均价线不超过0.2%；当前再次下跌且仍在线下 |
| 跌破整理区 | 前10根连续分钟收盘振幅不超过1%；当前收盘跌破其最低收盘 |
| 急涨反转 | 前5根连续分钟收盘曾较首根上涨至少2%；当前较高点回撤至少0.5%并低于均价线 |

上述数字是实现时提出的可检验定义，尚未经收益验证；整理区使用分钟收盘，非完整K线高低点。触发卖出若受T+1或行情/成交条件限制，将保存待卖意图，后续满足条件再模拟成交。

数据按约30秒检查已完成分钟；不是逐笔盘口，可能漏掉分钟内炸板又回封。消息在网页打开时轮询显示，关闭网页不发送外部推送。行情来源和时间随结果保留。没有有效行情时不伪造买卖。

## 三策略对照

策略模拟提供三个并列查看位置，可分别选择已保存策略。每套显示总权益、盈亏、仓位、持仓、退出保护和委托成交明细；查看对象切换不会改变策略运行状态。自动刷新保留已展开的规则、委托与执行记录。窄屏纵向排列。

编辑区可折叠，保存成功后自动收起；校验或保存失败时保留输入，继续编辑。通过“编辑策略”打开已有配置。“保存修改”沿用当前账本和启停状态，新规则从下次检查生效。“另存为新策略”创建独立账本。“删除策略”需要按名称确认，随后停止模拟，从列表移除并归档账本。新建或另存后需单独启动，需要在对应卡片启动定时模拟。

最多同时运行3套自定义策略，每套独立10万元；原“模拟交易”的今日主线和三维选股2个账户继续独立运行，合计5个账户。三个自定义策略可同时进行执行检查；完整市场扫描仍按服务限流排队，不保证同一时刻完成。

## 综合分优先买入

先按用户公式判断是否入选，再按已保存的排序方式由高到低选择。综合评分复用版本化日线技术因子：结构40%、趋势30%、量价动量30%，满分100分；候选池与三维扫描仍独立，不额外套用85分门槛。

- 结构：突破前20日最高价85分，否则高于MA20为65分，其余30分。
- 趋势：40 + 近5日涨幅百分数 × 2.5 +（高于或等于MA20加20），限制在0至100分。
- 量价动量：MA5 > MA10 > MA20为40分，否则10分；MACD柱为正加30分；当日量/前5日平均量至少1.2加30分，否则10分，最高100分。

评分至少需要35根有效日线和有效历史量。只在有可靠数据时给分，历史不足明确排除，不将缺失资金补成正面依据；评分本身不含主力资金，也不是胜率。盘中当日日线及当日量尚未结束，评分会变化。

完整市场扫描和提交前复核共用同一评分函数，均以分数降序、代码升序排序；全市场入选先取前50名做实时分钟与公式复核，再受持仓、待买名额、资金、最小单位及仓位上限约束。评分只决定提交顺序，不保证成交、不强行凑满5只。界面可展开分项和依据，委托记录保留提交时得分。

公式支持64条语句，分号分隔的表达式可跨行。CODELIKE只接受数字代码前缀，不能执行任意字符串代码。BARSLAST按已取得的历史序列计算，未曾满足时按已取得周期数计；BARSCOUNT同样基于取得序列，不是直接读取上市天数。ZTPRICE按公式给定比例将价格四舍五入至分；复权、除权除息、ST或特殊交易安排需单独核对，公式内的比例不替代官方涨停价。

NAMELIKE按已核验名称的字面前缀匹配，例如ST或*ST；星号在这里作为名称字符，不是通配符。名称缺失或仅有股票代码时报告缺失，不直接按普通股的比例计算。此上下文用于当前选股；历史名称变更需要另外提供对应日期的名称，不能用当前ST状态替代历史状态。模拟成交仍遵循当前不买入ST的执行规则。
