# 开发约定

本仓库是势研网站代码的开发来源。使用分支提交更改，提交前运行对应测试；通过 Pull Request 审查后合并到 `main`。线上部署读取明确的提交版本，先备份代码并验证接口，失败则回滚。

- 运行状态和凭证仅保存在 `.runtime/` 或服务环境变量中，禁止提交账本、笔记数据库、Token、Cookie、netrc 或 HAR。
- `.runtime/paper-trading.sqlite3` 与 `.runtime/yeren-notes.sqlite3` 是部署实例的数据，升级代码不覆盖它们。
- 行情来源、源日期、源时间与获取时间分别记录；缺失或过期数据不冒充实时数据，演示数据仅用于明确选择的演示模式。
- 今日主线和三维选股保持独立候选池；主线资格先于排序，不强制每天存在主线；三维只保留85分及以上。
- 模拟账户采用前向成交、T+1、费用和仓位约束；测试使用临时数据库，不修改线上账本。
- 一次部署保留单应用进程；当前缓存和扫描任务不支持多个独立 worker 共享。

Python 测试：`TDX_NO_PAPER_WORKER=1 python -m unittest discover -s tests -v`。
前端测试：逐个运行 `node tests/*.cjs` 对应的单个文件，或参考 GitHub Actions 中的循环。

旧的本机研究记录、第三方截图、视频、逐字稿和个人指标草稿不随公开代码发布。
