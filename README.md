# 势研 · A 股研究终端

基于 Flask 的 A 股行情研究网站，包含今日主线、策略解读、自选监控、三维选股、野人笔记、双账户模拟交易和自定义策略模拟和历史回溯。

代码用于策略研究与前向模拟，不连接真实证券交易。公开数据源可能延迟或不可用，筛选规则尚未完成收益验证。

## 本地启动

建议使用 Python 3.11：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

浏览器打开 `http://127.0.0.1:8765`。Mac 用户完成依赖安装后，也可以双击 `启动势研.command`，使用 `http://127.0.0.1:8766`。

选择“演示样本”或访问 `http://127.0.0.1:8765/?mode=demo` 可体验合成数据。真实行情失败时不会自动替换为演示数据。

## 功能

- **今日主线**：结合当日与多日资金、上涨宽度、涨停数量和连板高度，区分确认主线、资金趋势及潜在待涨。可以没有确认主线；角色缺位不补齐。
- **策略解读**：每个板块内显示入选原因、资金依据及板块内龙头、趋势、补涨的个股解读。
- **自选监控**：按名称或代码添加股票，可选填成本，按持仓状态观察试仓、加减仓、压力位、支撑及止盈止损条件。观察池保存在当前浏览器。
- **三维选股**：独立检验板块动量，再按结构、趋势、量价因子评分，仅保留综合分85及以上。
- **野人笔记**：记录来源、摘要、适用条件、操作要点和核验状态。公开仓库仅带目录元数据，不带个人笔记数据库或视频逐字稿。
- **模拟交易**：两个独立账户，各初始10万元、最多5只、默认仓位上限70%；支持自动策略及手动模拟。执行包括后续新分钟确认、T+1、费用和流动性约束，逐只解释未交易原因。
- **操作提醒**：五套模拟账户的委托、成交、撤销、拒绝、到期和持仓信号保留网页未读队列；HTTPS部署并取得浏览器授权后可发送系统桌面通知，无需网页置顶。签名密钥和浏览器订阅仅保存在运行目录。

- **策略模拟**：输入受支持的选股公式，在固定北京时间自动模拟买入；独立账本，支持涨停保护、1分钟涨速和固定止盈线之前的浮盈保护。[规则与限制](docs/strategy-simulation.md)。

- **历史回溯**：对已保存的公式策略选择日期区间，14:30选股、收盘价模拟买入，展示扣费收益、持仓、交易、净值曲线和数据缺口。五套模拟账户的最长持仓开关默认开启，5个交易日到期，连续封板延持。

主线与三维候选池独立。目标采用历史压力区域，止损与剩余盈亏比共同约束入场；入选或高分不等于当前买点。实际扫描有范围与数据覆盖限制，页面会标明。

## 数据源

价格与分钟线包含东方财富、腾讯、通达信普通行情的备用机制；资金数据独立校验日期、口径及覆盖。普通价格接口不等于已取得主力资金。

Tushare 已提供可选适配，需要自行配置 Token 并验证相应权限。盘中日线、完整分钟线和盘后资金历史分别核验；未配置时不参与切换。QMT／迅投目前提供客户端连通性检查工具，尚需账号、客户端及数据权限才能进一步接入。

## 测试

```bash
TDX_NO_PAPER_WORKER=1 python -m unittest discover -s tests -v
```

安装 Node.js 后运行前端测试：

```bash
for test in tests/*.cjs; do
  node "$test"
done
```

GitHub Actions 会运行上述测试。测试使用隔离数据与临时账本；不应依赖生产数据库或真实账号凭证。

## 项目结构

```text
app.py                         Flask入口与旧版看板
terminal_api.py                API、缓存和扫描任务
terminal_engine.py             日线因子、压力位与分钟信号
terminal_mainline.py            板块资格、评分及角色筛选
terminal_quotes.py             行情来源与切换
terminal_funds.py              盘中及多日资金校验
terminal_tushare.py            可选授权数据源
terminal_paper*.py             模拟账本与执行引擎
terminal_notes.py              笔记存储
static/、templates/            网页
scripts/                       笔记处理工具
tools/                        可选数据源配置及检查工具
tests/                        Python及JavaScript测试
```

## 运行数据

运行时会创建 `.runtime/`。模拟账户、个人笔记、数据源配置和日志均属于部署实例，不纳入 Git。更新代码必须保留已有运行目录；当前采用单进程、多线程部署。

凭证仅放在服务环境变量或权限为600的本机文件中。不要把 Token、Cookie、netrc、HAR、数据库、视频素材或生产部署资料提交到公开仓库。
