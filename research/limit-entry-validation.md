# 连板分类研究与冻结验证

本轮研究将一进二、二进三和首次分歧分开。**一进二是在第二个板打板介入，二进三是在第三个板打板介入**，观察买入之后的涨幅；不是按第二天开盘价买入，也不以最终达到四板反选候选。

研究区间为2025-10-01至2026-11-13。固定在市普通主板池3,194只，逐日核对历史ST，取得12,780个首板观察、2,083个二板观察。当前股票主档仍有生存者偏差；创业板、科创板20%制度不混入本主板研究。原始行情、逐股结果、研究模型和账户数据只保存在实例运行目录。

## 探索结论

- **二进三容量换手型**值得优先验证：首板、二板均非一字，二板量比首板温和增加，具有成交容量。预设市值分箱与换手类型交叉探索得到73次次日盘中三板触板，隔日收盘相对打板价中位变化约+1.16%。后期只有18例，不能宣称独立样本外验证。
- **两连板后的温和休整**应与高位首阴分开。首次断板时量能受控、收盘守住短期结构的一类相对较好，但后期收益特征减弱，不能外推到所有龙头首阴。
- **一进二低位修复首板**相对可观察，尚不足以固定为盈利公式。
- “必须缩量”“必须窄平台”“越早上板越好”均不能单独作为统一买点。封板比例、隔日溢价与持续持有回报是不同目标。

以上均为条件价格路径，不是已确认成交、扣费、动态退出后的账户收益。原历史已经多轮参与探索，前后期只做稳定性复核。

## 冻结的三组条件

| 组别 | 信号在何时可知 | 条件 | 首阶段处理 |
| --- | --- | --- | --- |
| 二进三容量换手型 | 前日二板收盘 | 首板、二板均非一字；1 < 二板量/首板量 < 2；估算流通市值至少100亿元 | 核验次日开盘低于涨停且盘中触板的成交证据 |
| 两连板后温和休整 | 首次断板收盘 | 原两连板；当日量/此前5日均量≤1.5；收盘≥含当日MA3；收盘位于当日高低区间上半部；非一字跌停 | 核验次日非涨跌停开盘及开盘成交证据 |
| 一进二低位修复观察组 | 前日首板收盘 | 非一字；首板前60日位置≤30%、20日涨幅<0；按研究分类顺序排除窄平台突破 | 仅观察，不生成成交或收益 |

市值是由当日价格、成交股数与换手率反推的估算值。100亿元、1—2倍是本次观察分箱，不是最优参数。温和休整允许量达到前5日均量的1.5倍，**不等同于严格缩量**。首次阴线（收盘低于开盘）也不等于首次断板。

## 验证阶段

1. **冻结协议与候选**：保存规则、版本、研究输入及交易日历哈希、所用代码哈希、费用和预定风控口径。筛选只读取信号日及此前特征，不读取未来涨幅、打板日收盘是否封住、未来开盘价等标签。
2. **成交证据和分钟数据审计**：使用本机缓存核对历史分笔的日期、来源、获取时间、成交量、高低收；交易日由显式市场日历决定，不用工作日代替。缺失、异常、观察期不足与未触板分开记录。
3. **待执行的退出与组合验证**：先确定成交情景，再复用原1分钟退出、T+1、费用、最长持仓及连板延持规则；最后验证独立资金组合和未来观察。首个5日窗口数据完整，不代表连板延持的全部退出数据已经完整。

当前工具实现第1、2阶段。**它不启动自动前向进程，不写当前五套账户，不生成委托、成交或收益，不代表策略已经验证通过。** 冻结协议中的账户、退出参数是下一阶段的约束，尚未在本工具中模拟。

### 为什么触板不能直接记成交

全天一字不默认成交。封板后的成交打印即使持续出现在涨停价，也不能反推自己的排队位置。工具区分：未触板、一字、开盘涨停特殊段、分钟数据未核验、触板但队列成交未确认、后续不同分钟观察到低于涨停价的成交。

“后续成交穿价”只能作为保守执行情景的证据；工具仍不确认真实订单成交。同一时间戳分钟内触板和回落的先后不据此推定。开盘策略也需核验实际开盘成交，不能拿缺失分笔补造成交。涨跌停价按前收及比例四舍五入至分，不固定用10%乘积作未取整价格。

## 使用方式

所有输入、输出均使用本机运行目录。新实验使用新目录；已冻结协议和候选不覆盖。补齐数据后可在同一冻结运行目录重跑审计，输出新的不可覆盖审计快照。下面的路径是示例，不含任何部署信息。

```bash
TDX_NO_PAPER_WORKER=1 python tools/limit_entry_validation.py freeze \
  --study .runtime/limit-entry-study/with-chips.json \
  --calendar .runtime/limit-streak-study/calendar.json \
  --output .runtime/limit-entry-validation/run-001

TDX_NO_PAPER_WORKER=1 python tools/limit_entry_validation.py audit \
  --run .runtime/limit-entry-validation/run-001 \
  --daily-dir .runtime/limit-entry-study/daily \
  --daily-dir .runtime/limit-pattern-study/daily \
  --ticks-dir .runtime/replay/ticks
```

- `manifest.json`：冻结口径、来源哈希与阶段状态。
- `signals.json`：只包含信号日可知的输入和候选；不复制未来收益标签。
- `audit.json`（初次）及`audit-*.json`（后续快照）：逐例成交证据、首个5日窗口的分钟覆盖、缺口清单。`actual_fills=0`、`pnl_status=not_calculated`。

输入研究JSON包含`start/end/universe/complete/entries/posts`；`complete`必须等于`universe`。`entries`使用代码、日期、首板/二板阶段、前期位置和涨幅、首板突破状态、首板/二板一字标志、二板相对量及市值估算；`posts`使用首次断板标签、已知高度、当日相对量、MA3、收盘位置及一字跌停标志。数值单位与上表一致，布尔标志必须明确提供。日线输入采用带`source/retrieved_at`的BaoStock字段对象；成交量单位股。分笔输入带日期、来源、获取时间，成交量单位手；核验时显式转换。

## 筹码与其他缺项

新增的筹码研究是日线、换手衰减的**自建模型估算**，未复刻通达信历史快照，不是逐户持仓或主力成本。完整120日窗口、未知成本残留和股本变化门槛后保留有效子样本，并做窗口/衰减敏感性对照。未得到“越集中或获利盘越高越适合追板”的一致证据；它与量价同源，不重复当作独立资金证据。筹码没有加入本次冻结买入条件。

全周期点时板块资金、龙虎榜、股东户数/机构持仓变化、解禁压力、逐笔封单及队列尚未完整接入；不能用当前数据倒填历史，也不能从缺失数据推断没有主力或没有催化。
