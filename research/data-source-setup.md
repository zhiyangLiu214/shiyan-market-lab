## Tushare

官方入口：[Tushare](https://tushare.pro/)。账号 Token 与数据权限分别检查；有 Token 不代表具备实时和资金权限。

已实现的独立能力：

| 接口 | 用途 | 限制 |
| --- | --- | --- |
| `daily` + `rt_k` | 历史不复权日线与当日盘中日线 | 盘中须取得带源日期和时间的实时日线；不拿昨日收盘当作今日价格 |
| `rt_min_daily` | 当日开盘以来完整一分钟 OHLCV | 单独的实时分钟权限；过滤未闭合分钟，不用单根最新分钟冒充全天分时 |
| `moneyflow_dc` | 个股已完成交易日资金历史备用 | 原始金额万元转为元；排除今日，不能当作实时资金 |
| `moneyflow_ind_dc` | 同口径行业资金历史备用 | 原始金额为元；按板块代码匹配，不跨来源按名称拼接；返回行数达到上限时拒绝不完整数据 |

历史日线成交额从千元转为元；盘中成交量从股转为手。盘中数据缺少明确源日期、时间陈旧、代码不符或 OHLCV 无效时，继续使用其他有效来源。

在网站服务器 `/app` 的交互终端执行：

```bash
cd /app
.venv/bin/python tools/configure_tushare.py
.venv/bin/python tools/check_tushare.py
```

配置工具隐藏输入，不把 Token 放在命令行或聊天中，保存到 `.runtime/tushare-token`，权限为 600。以服务运行账号执行；root 执行时按 `.runtime` 目录归属设置文件归属。已有 `TUSHARE_TOKEN` 环境变量会优先使用，文件更新不覆盖该变量。

网站会读取凭证文件，无需通过网页传密钥。未配置时下拉项禁用；配置后可以选择优先级，实际权限仍逐项验证。调用失败会限速和退避，不回退为演示数据。历史备用仅在同口径历史接口失败时使用，来源会显示在板块及个股资金区域。

检查工具只读取数据，不开通权限或操作交易。检查失败应先确认账号权限及额度，再决定是否购买；本次没有购买授权。

官方文档：[HTTP协议](https://tushare.pro/document/1?doc_id=130)、[实时日线](https://tushare.pro/document/2?doc_id=372)、[完整当日分钟](https://tushare.pro/document/2?doc_id=457)、[个股盘后资金](https://tushare.pro/document/2?doc_id=349)、[板块盘后资金](https://tushare.pro/document/2?doc_id=344)。请求固定发往官方 HTTPS 域名，禁止转发重定向中的凭证。
